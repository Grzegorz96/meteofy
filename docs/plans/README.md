# Plans

Drop larger implementation plans here (one markdown file per initiative). Keep them short: goal, scope, steps, risks, and links to PRs.

Example name: `2026-xx-migrate-weather-fetch-to-api.md`.

Before writing a plan, skim [../architecture.md](../architecture.md) and [../../AGENTS.md](../../AGENTS.md) so the scope matches the monorepo (`apps/web`, `apps/api`, `packages/shared`). When a plan ships or is abandoned, update or remove the file and note it in the PR.
